# Screenshots

This directory should contain screenshots for the PWA:

## Required Images

1. **desktop.png** (1920x1080) - Desktop view screenshot
2. **mobile.png** (750x1334) - Mobile view screenshot

## How to Create Screenshots

### Desktop Screenshot
1. Open the app in a desktop browser
2. Set window size to 1920x1080
3. Navigate to an interesting period (e.g., 117 CE - Greatest Extent)
4. Take a screenshot
5. Save as `desktop.png` in this directory

### Mobile Screenshot
1. Open browser DevTools (F12)
2. Enable device emulation (iPhone 6/7/8 or similar)
3. Navigate to an interesting period
4. Take a screenshot
5. Save as `mobile.png` in this directory

## Temporary Placeholders

Until real screenshots are added, the PWA will still work without them.
Screenshots are optional but recommended for app stores and installation prompts.
